# SauceDemo E-Commerce QA Audit

Comprehensive functional testing, test case design, and defect reporting for the SauceDemo e-commerce platform.

## 📌 Project Overview
The objective of this project is to perform end-to-end functional testing on key user journeys, identifying edge cases, boundary condition failures, and critical usability defects.

## 🛠️ Tech Stack & Methodologies
* **Testing Types:** Functional Testing, Boundary Value Analysis (BVA), Negative Testing, Regression Testing.
* **Documentation:** Markdown, GitHub Issues (Bug Tracking).
* **Test Design:** Standard STLC (Software Testing Life Cycle) test cases and 3-block bug reports.

## 📁 Repository Structure
* `/docs` — High-level Test Plan and test strategies.
* `/test-cases` — Detailed test cases covering Happy Paths, Edge Cases, and Negative scenarios.
* `/bug-reports` — Documented defects following professional severity/priority classifications.
* `/api-tests` — API test collections and assertions (In Progress).

## 🚀 Scope of Testing
1. **Authentication Module:** Login valid/invalid inputs, locked-out users, and edge cases.
2. **Shopping Cart & Inventory:** Item sorting, cart persistence, and boundary limits.
3. **Checkout Flow:** Required field validation, data-type handling, and total calculation.
